1. README

            

                
Sistem Manajemen Game Roblox adalah aplikasi web interaktif untuk mensimulasikan pengujian dan perbaikan validasi pada 5 modul utama pengelolaan katalog game Roblox. Proyek ini menerapkan materi Software Maintenance (Corrective, Preventive, dan Adaptive Maintenance) dengan membandingkan versi BUG (v1.0.0) dan FIX (v1.1.0) dalam satu tampilan.

                
Fitur Utama

                
    
                    
  1. Navigasi 5 modul pengujian spesifik (Nama Game, Pemain Aktif, Harga Game Pass, Diskon Item, Rating Usia).
    2. 
                    
  2. Dashboard statistik dinamis yang memantau log pengujian BUG dan FIX secara langsung.
    3. 
                    
  3. Tampilan kode sumber JavaScript sebelum dan sesudah perbaikan yang berganti otomatis sesuai tab modul.
    4. 
                    
  4. Penyimpanan riwayat data valid vs tidak valid menggunakan browser localStorage.
    5. 
                

                
Teknologi

                HTML5CSS3 (Responsive)JavaScriptLocalStorage
            


            
2. Bug Report

            

                
BUG-001 — Nama game menerima angka semua (12345), simbol, kosong, & duplikat

                Severity: MediumStatus: Fixed
                
Langkah reproduksi: Pilih tab 1. Nama Game, masukkan 12345 atau Brookhaven RP, lalu klik Jalankan BUG.

                
Perbaikan: fixNamaGame() menolak spasi kosong, simbol khusus, string angka semua, serta mencegah duplikasi katalog.

            

            

                
BUG-002 — Jumlah pemain aktif menerima nilai negatif (-5000) & desimal

                Severity: HighStatus: Fixed
                
Langkah reproduksi: Pilih tab 2. Pemain Aktif, masukkan -5000, lalu klik Jalankan BUG.

                
Perbaikan: fixPemainAktif() memvalidasi bilangan bulat ≥ 0.

            

            

                
BUG-003 — Harga Game Pass Robux menerima nilai negatif (-100)

                Severity: HighStatus: Fixed
                
Langkah reproduksi: Pilih tab 3. Harga Game Pass, masukkan -100, lalu klik Jalankan BUG.

                
Perbaikan: fixHargaRobux() membatasi harga bilangan bulat antara 1 – 100.000 Robux.

            

            

                
BUG-004 — Diskon item melebihi 100% (150%) menghasilkan tagihan minus

                Severity: HighStatus: Fixed
                
Langkah reproduksi: Pilih tab 4. Diskon Item (%), masukkan 150, lalu klik Jalankan BUG.

                
Perbaikan: fixDiskonItem() membatasi rentang diskon hanya 0% – 100%.

            

            

                
BUG-005 — Rating usia menerima kategori sembarang di luar standar Roblox

                Severity: MediumStatus: Fixed
                
Langkah reproduksi: Pilih tab 5. Rating Usia, masukkan Bebas, lalu klik Jalankan BUG.

                
Perbaikan: fixRatingUsia() membatasi input hanya pada All Ages, 9+, atau 13+.
